entry points and linked resources. Three were contributors evaluating other
authors' work; a fourth had fresh context for systems/code review. They were
instructed not to read rubrics or earlier results. The main author assessed the
actual responses afterward against [these scenarios](../expansion-scenarios.json).
This is a qualitative forward evaluation, not a calibrated benchmark or player
study. The [nine v0.1.0 scenarios](v0.1.0.md) are historical results, not reruns.

## Defects and refinements before release

- **Offline exact arithmetic:** an independent Fraction oracle found that the
  initial 192-digit Decimal context rounded a valid mixed-magnitude total by
  `10^-62`. Precision is now 320, with a documented bound of 264 positions for
  accepted inputs. The repository includes an exact rational regression. The
  reviewer reran the unchanged independent suite: all 15 methods passed,
  including 200 seeded rational comparisons and 24 invalid-input subcases.
- **Claim namespace:** offline claim IDs now include currency as well as earning
  stream and interval; settled history is explicitly scoped to that stream and
  currency. A regression checks separation without re-keying on rule changes.
- **Contrast threshold:** a direct Python API call with an extremely large
  integer now gets a clean invalid-input error; normal CLI behaviour was already
  bounded. The invalid-threshold regression covers it.
- **Profile ambiguity:** duplicate profile JSON keys now fail before destination
  mutation instead of silently selecting the last definition. A regression
  verifies the destination remains absent.
- **Promise preservation:** future product wording cannot narrow already-sold
  all-ads-removal rights; restored legacy purchasers need their original contract.
- **Native challenge recovery:** Apple challenge scores must not be blindly
  resubmitted on launch when Game Center already owns offline recovery.

## Limits

Scenario answers exercise decision guidance and resource loading. They do not
execute Godot/native adapters, game saves, notification delivery, store purchases,
real leaderboards, player studies or live experiments. Current documentation was
checked for selected policy/API claims, including unexpected newer platform
capabilities. Raw evaluator traces are excluded from the public repository;
this record preserves substantive decisions, failures, fixes and test scope.
