# Skill catalogue

Install all skills for lifecycle coverage or select individual folders. The
director routes broad requests; specialists work without sibling dependencies.

| Skill | Use when | Typical result |
|---|---|---|
| [ad-game-director](skills/ad-game-director/SKILL.md) | Planning or auditing across disciplines | Project context and prioritised work package |
| [game-concept-and-loops](skills/game-concept-and-loops/SKILL.md) | Choosing a concept or defining player decisions | Game brief and prototype hypothesis |
| [game-prototyping](skills/game-prototyping/SKILL.md) | Turning a design into a playable learning build | Bounded vertical slice and playtest plan |
| [game-feel-and-onboarding](skills/game-feel-and-onboarding/SKILL.md) | Improving controls, feedback or the first session | Interaction changes and onboarding journey |
| [game-progression-and-economy](skills/game-progression-and-economy/SKILL.md) | Tuning difficulty, currencies, rewards and unlocks | Progression model and deterministic economy scenarios |
| [game-retention-and-liveops](skills/game-retention-and-liveops/SKILL.md) | Diagnosing return behavior or planning sustainable events | Retention hypotheses and content cadence |
| [game-art-audio-and-content](skills/game-art-audio-and-content/SKILL.md) | Establishing visual/audio direction and production | Asset brief, pipeline and budgets |
| [game-ad-monetization](skills/game-ad-monetization/SKILL.md) | Choosing ad formats, placement, rewards and purchase promises | Placement matrix and monetisation experiments |
| [game-ad-integration](skills/game-ad-integration/SKILL.md) | Building or fixing ad lifecycle and reward delivery | Adapter/state contract and failure-case verification |
| [game-ad-operations](skills/game-ad-operations/SKILL.md) | Diagnosing provider readiness, delivery and yield | Account/build gates and request-to-revenue investigation |
| [game-privacy-and-platform-policy](skills/game-privacy-and-platform-policy/SKILL.md) | Resolving audience, consent, data and store requirements | Current source-grounded implementation checklist |
| [game-analytics-and-experiments](skills/game-analytics-and-experiments/SKILL.md) | Defining metrics or evaluating a test | Event dictionary, mature cohorts and experiment plan |
| [game-quality-and-release](skills/game-quality-and-release/SKILL.md) | Shipping a verified mobile build | Release checklist and evidence-bound rollout decision |
| [game-size-and-performance](skills/game-size-and-performance/SKILL.md) | Reducing app bloat or setting package/memory budgets | Dated store limits, artifact inventory and measured compression plan |
| [game-growth-and-acquisition](skills/game-growth-and-acquisition/SKILL.md) | Improving store conversion or acquiring players | Store/creative test and attribution plan |
| [game-profitability-and-priorities](skills/game-profitability-and-priorities/SKILL.md) | Choosing the next investment | Revenue/CPI sensitivity and priority ledger |

Keep buying acquisition ads separate from serving in-game ads. Connect both
through explicit cohort, attribution, revenue and cost definitions.
