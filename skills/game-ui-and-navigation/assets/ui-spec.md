## Evidence card

project hypothesis / success measure / guardrails / observed result or pending.

## Review artifacts

Screen map, wireframe, annotated mockup, component sheet and test record.
Generated visuals must be labelled proposals. Keep production strings editable
and localisable; attach alt text or an equivalent written explanation.
