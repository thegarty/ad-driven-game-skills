# Overgrowth: relevance and recovery before frequency

Evidence reviewed: **2026-10-25 development review**, sanitised for this library. The original private report is not required to use this skill.

- **Source-tested snapshot:** an ad initialization timeout could disable opportunities for the session; guarded retries restored eligible pre-show opportunities. A successful retry still needed a separate Watch action.
- **Simulated:** fixed daily offers became comparatively small as ordinary progression earnings grew. Synthetic strategy profiles exposed a possible value mismatch; they did not establish a new optimal reward.
- **Source-inspected:** start and completion events alone could not explain whether players saw or selected an offer.
- **Measured live, limited:** the review had only a small early provider sample. It did not establish retention lift, sustainable revenue per user or acquisition viability.

Reusable decision: audit opportunity eligibility, technical availability, visibility and progression-relative value before increasing interruptions. Treat a proposed improvement as a hypothesis until comparable player cohorts support it.

Do not inherit the game's exact limits, reward values, progression duration or optional-video-only model as universal defaults. No private account data, source code or telemetry is included here.
